# Orçamento Pessoal e Controle de Gastos com NotebookLM

## Descrição
Este projeto documenta o uso do NotebookLM como ferramenta de aprendizagem ativa
para o estudo de orçamento pessoal e controle de gastos.

Foram utilizadas fontes em vídeo e texto, perguntas estratégicas e testes de prompts
para a construção de um miniguia de estudo.

## Ferramentas
- NotebookLM
- GitHub
- Fontes abertas (YouTube e PDFs)

## Estrutura
- Fontes utilizadas
- Perguntas e prompts
- Miniguia de estudo
- Reflexão final
